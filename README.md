# S.A Projeto Movix

## Descrição
  O Movix é um sistema ferroviário desenvolvido para gerenciar informações de usuários e operações relacionadas ao controle de dados do sistema.

## Objetivo
  Desenvolver uma aplicação web organizada e funcional, aplicando conceitos de programação, banco de dados e interface gráfica.

## Funcionalidades
- Sistema de login
- Cadastro de usuários
- Gerenciamento de dados (CRUD futuramente)

Objetivo

O objetivo do MOVIX é criar uma interface simples e organizada para auxiliar no controle de uma operação ferroviária.

O sistema foi desenvolvido pensando em funcionalidades como:

Gerenciamento de trens;
Cadastro e consulta de usuários;
Controle de sensores;
Gerenciamento de rotas;
Monitoramento dos trens;
Visualização de alertas;
Geração de relatórios;
Dashboard com informações da operação.

Funcionalidades
Dashboard

Apresenta informações gerais do sistema e indicadores da operação ferroviária.

Monitoramento

Permite visualizar informações relacionadas ao acompanhamento dos trens.

Alertas

Apresenta alertas relacionados à operação ferroviária.

Trens

Permite visualizar informações da frota, como:

Código do trem;
Nome;
Linha;
Destino;
Velocidade;
Status.

Também possui botões para as ações de editar e excluir.

Sensores

Apresenta informações relacionadas aos sensores utilizados no sistema ferroviário.

Rotas

Possui informações relacionadas às rotas utilizadas pelos trens.

Usuários

Tela destinada ao gerenciamento dos usuários do sistema.

Relatórios

Página destinada à visualização de informações e relatórios da operação.

Desenvolvimento

O projeto foi desenvolvido em etapas, utilizando conceitos aprendidos durante o curso de Desenvolvimento de Sistemas.

Na etapa atual, as páginas que anteriormente poderiam ser desenvolvidas em HTML foram organizadas em arquivos PHP, permitindo uma estrutura preparada para futuras implementações.

Neste momento, o projeto não possui banco de dados nem funcionalidades de backend. Os dados apresentados nas telas são utilizados apenas para representar o funcionamento visual do sistema.

Interface

O sistema possui uma interface com:

Menu lateral;
Dashboard;
Cards informativos;
Tabelas;
Formulários;
Botões de ação;
Status dos trens;
Campo de pesquisa;
Navegação entre as páginas.

O estilo visual utiliza as cores e identidade do projeto MOVIX, com um layout voltado para um sistema de gestão ferroviária.
